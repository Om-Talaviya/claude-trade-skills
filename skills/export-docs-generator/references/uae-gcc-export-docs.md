# UAE & GCC Export Documentation Standards

## 1. Statutory Prerequisites for UAE & GCC Trade
- **TRN (Tax Registration Number)**: 15-digit Federal Tax Authority (FTA) identifier (e.g., `100XXXXXXXXX003`).
- **Customs Code (Dubai Customs / Bayan)**: Unique importer/exporter registration code registered on Dubai Trade Portal (Mirsal 2 system).
- **GCC Common Customs Law**: Standard 5% CIF tariff on imported goods unless originating within GCC member states or covered by CEPA/FTA.
